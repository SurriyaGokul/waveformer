# `src/tools/`

Small standalone visualization utilities that don't belong to a specific model
version.

| File | Key contents | Use |
|---|---|---|
| `visualize_flows.py` | `flow_to_color`, `visualize_sample`, `main` | Renders motion-interpolation optical-flow output as color-coded flow fields. Runnable directly: `python -m src.tools.visualize_flows --help` |
