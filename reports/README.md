# `reports/`

Standalone write-ups documenting a specific pipeline or audit in detail (as opposed to
`docs/`, which holds forward-looking task/design plans).

| File | Contents |
|---|---|
| `SWE_dispersion_postprocessing_pipeline.md` | Detailed documentation of the shear-wave dispersion post-processing pipeline (`src/analysis/dispersion.py`): the phase-velocity fitting method, validation scripts, and where it's used in production evaluation |
| `wavepinn_elastography_audit.html` | Standalone HTML audit report of the WavePINN elastography pipeline. Open directly in a browser: `open reports/wavepinn_elastography_audit.html` (or `xdg-open` on Linux) |
